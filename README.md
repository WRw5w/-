# QQ 聊天导出操作规范

供 AI 助手按需读取的中文 skill：[qq-chat-export / SKILL.md](skills/qq-chat-export/SKILL.md)。

针对 QQ 私聊/群聊导出，约束现有实例复用、账号确认、有限分页、临时启动、配置回滚与退出恢复，避免为导出反复启动完整机器人服务。仓库只保存通用文档，不存放聊天记录和账号运行数据。

使用方式：把 SKILL.md 交给执行助手，说明目标联系人或群名、导出日期范围和本地输出位置。也可以把 qq-chat-export 文件夹复制到所用工具的 skills 目录。

本仓库当前 URL 名称是普通 ASCII 短横线 `-`，码位 `U+002D`，没有隐藏字符。中文标题可以保留在文档中；如需更易辨认的仓库 URL，可另行改成 qq-chat-export，当前未执行改名。
